# Launch Checklist

> Indie launch OS

**Author:** zAx4hub

## Problem

Teams need a practical open toolkit for: **Indie launch OS**. Existing options are often closed SaaS or untested prototypes.

## Solution

`launch-checklist` is a complete, installable TypeScript/Node project by **zAx4hub** with real algorithms, CLI/demos, tests, and CI.

## Why different

- Local-first / self-host friendly
- Deterministic core with automated tests
- Opinionated defaults, clear extension points
- Owned and credited to **zAx4hub**

## Quickstart

```bash
cd launch-checklist
npm install
npm test
npm run demo
```

## Features

- Core engine for indie launch os
- CLI: demo / run / inspect
- Structured JSON reports
- Examples + fixtures
- GitHub Actions CI

## Architecture

`src/` holds pure engine logic; CLI and examples sit at the edges. Tests exercise the engine directly for speed.
